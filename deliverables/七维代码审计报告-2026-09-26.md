## 维度 3｜安全性 —— 评分 8.0

### 🔴 最高优先级：校验错误回显明文口令

`src/middleware/validateQuery.js:27`（已亲自复核源码确认）：

```js
return ApiResponse.codeError(res, 'VALIDATION_FAILED', { fieldErrors: errors.array() });
```

`errors.array()` 默认 formatter 返回**含 `value`（原始输入）的完整错误对象**，经 `apiResponse.js:94-95` 直接进响应体。触发点确为口令字段（`authRoutes.js:62` passwordStrengthCheck、`securityRoutes.js:130` 改密链、`authRoutes.js:81,117,144,153`）→ **口令强度/必填校验失败时明文口令被回显**，且前端 errorReporter 会采集响应体 —— 与 `app.js:374-377` 自己"对 404 打码防上报采集"的纪律**直接矛盾**。影响约 40+ 处调用点，修复只需一行 map 抽取 `{path, msg, location}`。
