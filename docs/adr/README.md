# 架构决策记录（ADR）

本目录收录系统关键架构决策的 ADR（Architecture Decision Record），用于沉淀「为什么这样做」的权衡过程，避免结论只散落在代码注释中（优化清单 H-2）。

## 约定

- 文件命名：`ADR-编号-主题.md`，编号只增不复用
- 每篇结构：背景 → 决策 → 理由 → 备选方案 → 后果与局限 → 关联
- 状态取值：`已接受`（当前生效）/ `已废弃`（被后续 ADR 取代，须注明取代者）
- 决策被推翻时不改写原文，新增一篇 ADR 说明取代关系
